# Источники данных — что проверено вживую 2026-10-12

Почему это файл, а не коммит-сообщение: здесь адреса сервисов, лимиты и цены, которых нет в коде и которые решают, что вообще можно построить.

## Вердикт
Строить можно: два главных неизвестных закрылись. Преступность отдаётся открытым ArcGIS FeatureServer с точками с 2015 года; транспорт считает 2GIS с демо-ключом (1000 единиц на API) или пакетом 10 000 единиц за 6 700 ₽/мес.

## Преступность — gis.kgp.kz (Комитет правовой статистики, ArcGIS Server 11.0)
- Каталог: `https://gis.kgp.kz/arcgis/rest/services?f=pjson` → папки `KPSSU`, `Hosted`. Сайт qamqor.gov.kz/crimemap — Vue-SPA, ссылается на `gis.kgp.kz/arcgis/apps/dashboards/`.
- Слой: `KPSSU/crime/FeatureServer/1` (слой 0 не существует), точки, `maxRecordCount` 5000.
- Поля: `yr`, `period` (месяц), `crime_code`, `hard_code` (тяжесть), `stat` (статья УК), `dat_sover`, `organ`, `reg_code`, `city_code` (Алматы = `1975`), `fz1r18p5/6` (улица/дом), `fe1r29p1_id` (место), `weekday`, `discontinued`.
- Счёт по bbox Алматы `76.75,43.15,77.15,43.42` без фильтра по году: **533 906** точек. Пример: 2015, ст.109, Панфилова 37, 76.942/43.269.
- Соседний слой `KPSSU/DTP/FeatureServer/0` — ДТП, 77 116 точек в том же bbox (`rta_date`, `vehicle_category`, `is_public_transport`). Кандидат на слой «опасные перекрёстки».
- Запрос: `/query?where=yr>=2023&geometry=<bbox>&geometryType=esriGeometryEnvelope&inSR=4326&outSR=4326&outFields=*&resultOffset=N&resultRecordCount=5000&f=json`.
- Не проверено: условия использования, стабильность при выгрузке 100k+ строк.

## Транспорт — 2GIS (docs.2gis.com, прочитано 2026-10-12)
- Routing API: авто, пешком, **общественный транспорт через `/public_transport/2.0`** с учётом расписания; до 12 точек для ОТ; с демо-ключом максимум 50 км между точками. Тарифицируется **маршрут** (пара точек).
- Distance Matrix API: тарифицируется **каждая пара** точек; в стандартном тарифе 25 точек отправления/прибытия на запрос; есть асинхронный режим.
- Isochrone API: пешком, авто, **ОТ** (метро, автобус, троллейбус); несколько длительностей за запрос; ключ демо или подписка.
- Лимиты демо-ключа: **1000 единиц всего** на каждый из Routing / Distance Matrix / Isochrone; 600 единиц в минуту.
- Цена пакетов (RUB, в месяц): Routing и Distance Matrix — 10 000 ед. = 6 700 ₽, 30 000 = 15 000 ₽, 50 000 = 20 000 ₽, 100 000 = 30 000 ₽; подписка на год −10 %. Ключ — через Менеджер Платформы (регистрация руками владельца).
- Не проверено: учитывает ли Distance Matrix время отправления (пробки), требует ли подписка юрлицо, работает ли ОТ-маршрутизация по Алматы с демо-ключом.

## Яндекс — отпадает
- Матрица расстояний / Router: бесплатного тарифа нет; 1000 запросов/сутки = 20 800 ₽/мес или 195 000 ₽/год; расширенная лицензия с правом **хранить** ответы — 226 200 ₽/год; стандартная разрешает кэш ≤30 дней. Источник: yandex.ru/dev/tariffs/doc/ru/matrix/prices.

## OSM (Overpass, bbox Алматы, 2026-10-12)
- 144 relation route=bus, 13 trolleybus, 2 subway; 104 различных `ref`; интервалы (`interval`) только у 6, PTv2 у 3 — расписания нет, GTFS из этого не собрать.
- 13 узлов `station=subway` (две точки «Қалқаман», дубли): Абай, Алатау, Байқоңыр, Жібек Жолы, Театр Әуезова, Мәскеу, Сайран, Райымбек батыр, Алмалы, Қалқаман, Бауыржан Момышұлы, Сарыарқа.
- overpass-api.de требует User-Agent (406 без него) и бывает занят; зеркало overpass.private.coffee. Geofabrik `kazakhstan-latest.osm.pbf` — 224 МБ, пока не нужен.
- Публичного GTFS Алматы нет: только статья 2022 (GeoJournal of Tourism and Geosites) и фид по 3 маршрутам Астаны (Data 2025).

## Воздух — airkaz.org
- `almaty.php` содержит встроенный JSON: 301 запись, поля `id, name, lat, lng, pm25, pm25ss, pm10, AQI, temp, humid, press, status, date, hour`; **84 различных датчика Алматы с координатами**, но «сегодня» отчитались только 4 — остальные записи 2019–2023.
- Архив: `https://airkaz.org/xls/daily_almaty_6oct20.xlsx` — «среднесуточные значения PM2.5 со всех датчиков, март 2017 – сентябрь 2020». Не скачан, структура не проверена.
- API нет. Сертификат на www.airkaz.org битый, без www — работает.
- Альтернативы: Almaty Air Initiative поставил 170 датчиков AirGradient (сентябрь 2026), дэшборд есть, API/лицензия не найдены; Казгидромет — 3 станции с PM2.5.

## Жильё и цены — krisha.kz
- Из krisha-scout/docs/research/krisha-site.md: кода там нет, только исследование. П. 5.3 соглашения запрещает автосбор; `window.data.advert` даёт `map{lat,lon}`, `priceM2`, `complexId`, `house.year`, `flat.building`.
- Для этой карты: цена м² вводится руками по районам (krisha.kz/analytics), объявления — не здесь.
