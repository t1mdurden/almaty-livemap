# almaty-livemap — PRD

## Что это
Личная карта Алматы: город разбит на гексы H3 (res 9, ~0.1 км²), у каждого гекса набор факторов удобства жизни, пользователь двигает ползунки весов и видит, где жить и покупать квартиру удобно именно ему. Один пользователь — владелец, который сейчас выбирает квартиру.

## Что делает
1. Считает слои офлайн-пайплайном (Python, uv) и складывает в один `data/out/hexes.geojson`: по фактору сырое значение и перцентиль 0–1.
2. Рисует их статичной страницей `web/index.html` (MapLibre GL из CDN, без сборки): балл = взвешенная сумма перцентилей, веса — ползунки, пересчёт в браузере.
3. Показывает попап по гексу с разбором балла и панель «Топ-20» с ценой м² по району.

## Факторы (порядок = порядок сборки)
| Слой | Источник | Статус источника |
| --- | --- | --- |
| metro_min — минуты пешком до метро | OSM | проверен |
| crime_rate — правонарушения 2023–2025 на жилую площадь | gis.kgp.kz ArcGIS | проверен, 534k точек |
| pm25_winter — зимний PM2.5 | airkaz.org датчики + архив xlsx | датчики проверены, архив нет |
| car_min / pt_min — доезд в 8:30 до точек владельца | 2GIS Distance Matrix / Routing | тарифы проверены, нужен ключ |
| transit_proxy — маршруты ОТ в 400 м | OSM | проверен, 157 маршрутов |
| cat15 — категории инфраструктуры в 1 км | OSM | проверен частично |
| price_m2 — цена м² по району | krisha.kz/analytics, руками | 8 чисел |

## На чём работает
- Python 3.12 через uv: h3 4, geopandas, shapely, pyarrow, requests, openpyxl.
- Overpass API (bbox 76.75,43.15 – 77.15,43.42), ArcGIS REST, 2GIS REST (ключ только из `TWOGIS_KEY`).
- Фронт: один HTML, MapLibre GL JS с CDN, GeoJSON рядом. Публикация — GitHub Pages.

## Чего нет и почему
См. `notSlices` в `.claude/slices.json`: отзывы по ЖК, планы метро/BRT (ручной geojson позже), GTFS/r5py (нет фида), Яндекс (дорого и нельзя хранить), сейсмика/шум/уклон (не проверены).

## Что требуется от владельца руками
1. Зарегистрироваться в 2GIS Менеджере Платформы, создать демо-ключ, положить в окружение `TWOGIS_KEY`.
2. Заполнить `config/destinations.yaml` — 3–5 точек (работа, родители, аэропорт).
3. Решить, покупать ли пакет 10 000 единиц (6 700 ₽), если `pipeline.reach plan` покажет, что демо не хватает.
4. Вбить 8 цен м² по районам в `config/prices.yaml`.
5. Создать репозиторий на GitHub (или разрешить `gh repo create`) для Pages.
